## Initial feasibility assessment

The funded rare-disease project was attractive because it offered a clinically important NLP setting, research-mentor sponsorship, and potential access to real workflows and annotation problems. The historical near-term scope included phenotype extraction, negation, experiencer, anatomy, temporality, ontology normalization, data preparation, and model testing.

**Stream 02 strategic judgment.** At the first review, cohort adjudication, onboarding, annotation guidance, multilingual coordination, and model exploration were still in progress. The project was therefore considered an excellent proving ground but an unsafe sole dependency for a four-year dissertation.

The dissertation needed a public-data-first path that remained useful if protected-data access or international collaboration was delayed.

The update increased confidence that the project was a credible near-term research asset. It did not reverse the recommendation against making it the dissertation's sole dependency.

## The two-track plan

**User-stated requirement.** The user proposed working on the funded project for the next several months while separately developing the broader dissertation.

**Stream 02 recommendation.** The resulting two-track strategy was:

### Track 1: funded-project learning and bounded ownership

- understand the data, workflow, annotation quality, context dimensions, baselines, and operational constraints;
- identify one bounded contribution the user could lead;
- seek a paper or reusable system without presuming authorship;
- clarify which code, methods, and documentation could support the dissertation or leave the restricted environment.

### Track 2: independent dissertation-method development

- formalize the broader problem of evaluation, evidence grounding, belief revision, uncertainty, and selective control;
- use public or synthetic data first;
- make progress independent of protected-data access;
- keep functional genomics, biomedical literature, or another domain available for validation.

The guiding historical recommendation was:

> Let CIL-FLARE inform and validate the dissertation, but do not let access to one dataset define the dissertation prematurely.

## Decision gates after the initial work period

Stream 02 proposed reassessing the project against six criteria:

1. a sufficiently novel methodological problem;
2. adequate data and expert annotation;
3. clear intellectual ownership and plausible lead authorship;
4. generalizability beyond rare-disease phenotyping;
5. acceptable completion risk;
6. support from an eligible adviser.

The user was also advised to clarify expected contribution, authorship, venue, dissertation reuse, software release, data restrictions, and institutional IP before investing heavily.

## Dependency and fallback reasoning

**Stream 02 strategic judgment.** A French or federated extension would add policy, privacy, coordination, annotation, and collaborator dependencies and should remain optional until formally authorized. A multi-component clinical pipeline was not automatically a dissertation contribution.

If the funded project passed the decision gates, it could become a high-value validation aim. If not, it could still produce clinical-data experience, a collaboration, a bounded publication, or a useful error taxonomy while the methods program continued elsewhere.

Functional genomics was the principal alternative application named in the archive, but it too required a credible collaborator and validation design. The two-track plan managed dependency risk; it did not eliminate the need to select a scientifically coherent primary domain later.
