# Discussion Archive

This directory stores important excerpts or exports from ChatGPT and Claude conversations that contain substantive reasoning relevant to dissertation strategy.

Recommended paths:

- `discussions/chatgpt/`
- `discussions/claude/`

Archive discussions that contain:

- dissertation rankings
- advisor analysis
- literature analysis
- proposed research programs
- publication strategy
- disagreements or revisions
- important decisions

Casual conversation does not need to be archived.

Raw discussion is supporting evidence, not the canonical project state. Accepted decisions belong in `decisions/decision_log.md`.
