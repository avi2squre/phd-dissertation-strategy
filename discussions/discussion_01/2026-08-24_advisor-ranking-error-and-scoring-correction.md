# 2026-08-24 — Advisor-ranking error and scoring correction

## Historical role

This entry preserves one of the most important methodological corrections in Stream 01. The user noticed that a ranking changed substantially after advisor-team advantage was added, even though every serious candidate appeared to have at least one plausible eligible primary advisor plus meaningful complementary expertise from the external advisor.

## Initial Stream 01 position

Stream 01 initially said advisor fit had been considered qualitatively but not as an explicit weighted variable. It then proposed a more explicit advisor-team analysis and produced a revised ordering that elevated a new hybrid category, **causal + neuro-symbolic agentic AI**, above the previous leading trustworthy-agentic direction.

It also initially suggested advisor fit might deserve roughly 10–15% of the final score.

## User challenge

The user asked why the ranking should change merely because advisor-team advantage had been added if every major candidate already passed the basic advisor-feasibility requirement.

That challenge exposed two simultaneous changes in the prior comparison.

## Later correction or qualification

Stream 01 explicitly acknowledged that the reranking was methodologically invalid as a before/after comparison because it had done two things at once:

1. added advisor fit as an explicit criterion; and
2. changed candidate definitions, especially by transforming "causal agentic AI / RWE" into "causal + neuro-symbolic agentic AI."

The revised #1 was therefore not the same candidate as the earlier #4.

### Core methodological lesson

**Candidate definitions must be frozen before comparative scoring.**

If a materially different hybrid is proposed, it should be treated as a new candidate rather than quietly modifying an existing candidate during ranking.

## Advisor feasibility versus advisor advantage

The discussion then separated two concepts that had previously been conflated.

### Stage A — advisor feasibility

A candidate should first answer whether there is a plausible advising configuration with:

- an eligible primary advisor;
- meaningful complementary contribution from the external advisor;
- plausible data, infrastructure, collaborators, or compute;
- sufficient methodological support to complete a PhD-scale program.

A severe failure here can eliminate or strongly penalize a candidate.

### Stage B — differential advisor-team advantage

Among candidates that already pass Stage A, advisor fit should normally be only a modest ranking factor.

The relevant question becomes whether one local configuration provides a **uniquely strong execution advantage**, for example:

- otherwise inaccessible data;
- unusually specialized methodological mentorship;
- established funded infrastructure;
- a mature benchmark/community;
- a ready collaborative network;
- a publication ecosystem that materially increases execution probability.

Without such a decisive difference, advisor advantage should not override larger differences in scientific opportunity, publication feasibility, or methodological value.

## Revised scoring logic

Stream 01 proposed a hierarchical framework:

### Feasibility filters first

- eligible advisor configuration;
- meaningful complementarity;
- plausible resources;
- PhD-scale depth and completion feasibility.

### Weighted comparison second

An illustrative later weighting assigned advisor-team advantage only a modest share of the score after feasibility was established. This historical move later informed the canonical scoring framework.

The exact numerical weight is a project decision, not established evidence.

## Fixed-category reranking

When the candidate definitions were restored to comparable forms, Stream 01 returned much closer to the prior ordering:

1. trustworthy agentic AI / autonomous workflow systems;
2. neuro-symbolic + metacognitive agents;
3. causal agentic AI / autonomous RWE generation;
4. evaluation / verification / safety of autonomous AI;
5. biomedical KG + LLM reasoning;
6. conventional clinical LLM / prediction systems.

The discussion emphasized that #1–#4 were close and that the ordinal ranking was provisional.

## Deeper possible common problem

Stream 01 noted that the leading families might ultimately be mechanisms around a deeper question such as:

> How can autonomous AI systems recognize and correct failures during high-stakes multistep reasoning?

Possible roles were:

- agentic AI = system architecture;
- neuro-symbolic reasoning = structured reasoning mechanism;
- metacognition = self-monitoring / corrective-control mechanism;
- causal inference = one validation mechanism;
- healthcare = primary high-stakes application/test domain.

### Strategic caution

The stream explicitly warned not to merge these prematurely. Doing so would make it difficult to determine which component creates the methodological novelty.

## Why this episode matters to repository governance

This correction directly motivated later process rules:

- freeze candidate definitions before ranking;
- separate hard feasibility filters from differential scoring;
- preserve corrections and rationale rather than only the final weight;
- do not average or compare rankings produced under different candidate definitions;
- use provenance so later reviewers can challenge the reasoning that produced a decision.

## Unresolved questions

1. What local resources would be sufficiently unique to justify increasing advisor-team weight for a specific candidate?
2. Should advisor-team advantage remain a numerical score or be represented qualitatively after the feasibility filter?
3. Which candidate definitions should be frozen before the first serious cross-stream ranking?
4. How should uncertainty about advisor availability or resource access be represented without treating speculation as fact?
