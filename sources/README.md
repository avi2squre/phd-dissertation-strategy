# Project Sources

Use this directory for the broader project source registry and source-type guidance.

Scientific and scholarly literature should be cataloged in the dedicated `literature/` archive. This `sources/` directory remains useful for official institutional sources, government/statistical sources, industry reports, and other non-literature materials that inform the project.

For each non-literature source, record:

- title
- author/organization
- year
- official URL or stable identifier
- source type
- why it matters to the dissertation decision
- key findings used
- limitations
- which candidate programs it informs
- where it is used in discussions, analyses, evidence notes, or decisions

## Source categories

### Academic / scholarly literature

Use `literature/index.md` and `literature/records/` as the canonical archive for peer-reviewed papers, systematic reviews, benchmarks, conference papers, preprints when necessary, methodological literature, and scholarly perspectives/roadmaps.

### Official institutional

University faculty profiles, program requirements, grant/project pages, government sources, and official statistics.

### Industry

High-quality reports used for adoption, market, workflow, labor-market, and commercialization signals.

## Important rules

- Do not use industry commentary alone to claim that a scientific research gap exists.
- A source should be traceable to the claim or decision it informs whenever practical.
- Do not store copyrighted full-text material merely for convenience when a stable citation, identifier, official/open-access link, and structured notes are sufficient.
