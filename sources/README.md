# Project Sources

Use this directory to maintain a structured bibliography and source notes without necessarily storing copyrighted PDFs in the repository.

For each source, record:

- title
- author/organization
- year
- DOI, PMID, arXiv identifier, or official URL
- source type
- why it matters to the dissertation decision
- key findings used
- limitations
- which candidate programs it informs

## Source categories

### Academic
Peer-reviewed papers, systematic reviews, benchmarks, conference papers, preprints when necessary, and primary methodological literature.

### Official institutional
University faculty profiles, program requirements, grant/project pages, government sources, and official statistics.

### Industry
High-quality reports used for adoption, market, workflow, labor-market, and commercialization signals.

## Important rule

Do not use industry commentary alone to claim that a scientific research gap exists.
