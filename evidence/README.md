# Evidence Workspace

This directory stores distilled evidence used to evaluate dissertation programs.

It is intentionally distinct from the scholarly literature archive in `literature/`.

- `literature/` answers: **What papers and scholarly sources have we examined, and what do they actually say?**
- `evidence/` answers: **What claims from those sources or other evidence streams are we using to compare dissertation programs?**

Recommended organization:

- `academic_literature.md` — distilled scientific claims, research-gap evidence, benchmarks, and methodological findings, linked back to `LIT-XXX` records when applicable
- `industry_evidence.md` — market adoption, workflow pain points, labor-market signals, and commercialization evidence
- `faculty_fit.md` — official faculty profiles, methodological expertise, datasets, infrastructure, and publication networks

## Evidence rule

Every substantive claim used to rank a dissertation program should identify its source type and confidence.

When a claim is derived from scholarly literature, cite the corresponding `LIT-XXX` identifier whenever practical so that the reasoning can be traced back to `literature/index.md` and `literature/records/`.

Distinguish:

- direct source-supported finding
- project inference
- strategic interpretation
- unresolved uncertainty

Industry evidence may support claims about demand, adoption, workflow problems, or commercialization, but it should not be treated as proof of scientific novelty.

A single paper should not normally be treated as sufficient evidence for a broad field-level novelty or saturation claim.
