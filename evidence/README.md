# Evidence Workspace

This directory stores distilled evidence used to evaluate dissertation programs.

Recommended organization:

- `academic_literature.md` — peer-reviewed papers, benchmarks, reviews, and primary scientific sources
- `industry_evidence.md` — market adoption, workflow pain points, labor-market signals, and commercialization evidence
- `faculty_fit.md` — official faculty profiles, methodological expertise, datasets, infrastructure, and publication networks

## Evidence rule

Every substantive claim used to rank a dissertation program should identify its source type and confidence.

Industry evidence may support claims about demand, adoption, workflow problems, or commercialization, but it should not be treated as proof of scientific novelty.
