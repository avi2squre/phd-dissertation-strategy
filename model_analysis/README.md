# Model Analysis Workspace

ChatGPT and Claude should preserve independent analyses here rather than overwriting each other.

Recommended paths:

- `model_analysis/chatgpt/YYYY-MM-DD_topic.md`
- `model_analysis/claude/YYYY-MM-DD_topic.md`

Each analysis should explicitly state:

1. the question being evaluated
2. evidence used
3. assumptions
4. recommendation
5. uncertainty
6. agreements/disagreements with the other model, if known
7. whether any accepted decision should be reconsidered

Do not force consensus. Meaningful disagreement should be investigated.
