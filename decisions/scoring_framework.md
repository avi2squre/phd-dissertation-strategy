# Dissertation Program Scoring Framework

This project deliberately separates internal strategic selection from faculty-facing scientific discussion.

## Internal framework

Candidate programs must first pass feasibility screening before numerical ranking.

### Stage A — Feasibility filters

A candidate should normally have:

- at least one plausible IHI primary advisor
- meaningful complementarity with Rui Zhang
- plausible data/resources/infrastructure
- PhD-scale methodological depth
- realistic completion feasibility

Candidates failing a major feasibility condition should be flagged before numerical ranking.

### Stage B — Weighted strategic evaluation

| Criterion | Weight |
|---|---:|
| Scientific novelty / importance | 15 |
| Publication feasibility | 15 |
| Publication decomposition / velocity | 12 |
| Citation / artifact-adoption potential | 8 |
| AI-obsolescence resilience | 12 |
| Cross-domain portability | 10 |
| US labor-market demand | 8 |
| Commercialization potential | 8 |
| Specialized-visa portfolio potential | 8 |
| Advisor-team advantage | 4 |
| **Total** | **100** |

Each criterion receives a score from 1–10.

Weighted contribution:

`(score / 10) × criterion weight`

The final score is the sum of weighted contributions.

Advisor availability is primarily a feasibility screen. Once a strong advising team exists, small differences in advisor fit should not dominate the research ranking unless one team provides a uniquely important advantage such as proprietary data, unusual methodological expertise, established infrastructure, funded project support, or a major collaboration/publication network.

## Faculty-facing framework

Faculty-facing discussion materials should not reproduce the internal weighted optimization matrix. Their purpose is to solicit expert scientific judgment about the candidate research programs.

Use qualitative assessments, evidence, and explicit uncertainty for:

| Faculty-facing dimension | Purpose |
|---|---|
| Scientific significance | Is the underlying problem important? |
| Novelty / research-gap headroom | Is there a consequential unresolved methodological gap? |
| Methodological depth | Can the work make substantive technical contributions rather than primarily applying existing methods? |
| Research-program coherence | Can the direction support multiple connected studies forming a coherent dissertation? |
| Feasibility / tractability | Can meaningful progress be made within the PhD timeline? |
| Evaluation tractability | Can contributions be rigorously evaluated against meaningful baselines and failure modes? |
| Generalizability | Can the methods contribute knowledge beyond one narrow healthcare application? |
| Local expertise and resources | Are the necessary advising expertise, data, infrastructure, compute, and collaborators realistically available? |
| Key scientific uncertainty | What important assumption or unknown should faculty help evaluate? |

Do not create false precision. Qualitative labels, evidence summaries, ranges, and question marks are preferable when evidence is weak.

## Comparison discipline

- Freeze candidate definitions before scoring or comparing.
- Do not add new methodological components to a candidate midway through comparison.
- If a materially different combination is proposed, create it as a separate candidate program.
- Record uncertainty and score ranges when evidence is weak.
- Do not average independent analysis scores mechanically; investigate meaningful disagreements first.
- Do not allow internal career, immigration, or commercialization objectives to distort the scientific framing of faculty-facing materials.
